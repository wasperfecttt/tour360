# Tour360 — запуск и деплой

MVP: клиенты регистрируются, загружают готовые 360° панорамы по комнатам,
получают публичную ссылку на онлайн-тур (просмотр через Pannellum.js).

## 1. Supabase (аккаунты, база, хранилище фото) — бесплатно на старте

1. Зайти на supabase.com → New project. Запомнить пароль от базы.
2. В Project Settings → API скопировать `Project URL` и `anon public key`.
3. В Storage → New bucket → имя `panoramas`, отметить **Public bucket**.
4. В SQL Editor → New query → вставить содержимое `sql/schema.sql` → Run.
   (Если бакет уже создан вручную, строку `insert into storage.buckets...`
   можно пропустить — она и так не упадёт благодаря `on conflict`.)
5. В Authentication → Providers убедиться, что Email включён.
   Если не нужно подтверждение почты для теста — в Authentication → Settings
   можно отключить "Confirm email".

## 2. Локальный запуск (проверить перед деплоем)

```bash
cp .env.local.example .env.local
# вписать туда NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_ANON_KEY
npm install
npm run dev
```

Открыть http://localhost:3000, зарегистрироваться, создать тур, загрузить
панорамы, нажать «Опубликовать», открыть ссылку /tour/<id>.

## 3. Деплой на Vercel (хостинг)

1. Залить проект в GitHub-репозиторий (приватный или публичный).
2. На vercel.com → Add New → Project → выбрать этот репозиторий.
3. В настройках проекта → Environment Variables добавить те же две переменные
   (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`).
4. Deploy. Vercel даст временный адрес вида `tour360.vercel.app`.

## 4. Свой домен

1. Купить домен (Reg.ru, Namecheap и т.п.), например `tour360.ru`.
2. В Vercel → проект → Settings → Domains → добавить домен.
3. Vercel покажет DNS-записи (обычно A-запись на его IP или CNAME) —
   прописать их у регистратора домена.
4. Подождать обновления DNS (от нескольких минут до пары часов) — Vercel
   сам выпустит HTTPS-сертификат.

## Что уже работает в MVP

- Регистрация/вход клиентов (Supabase Auth).
- Личный кабинет: список туров, создание нового.
- Редактор тура: загрузка нескольких панорам, переименование комнат,
  удаление, публикация/снятие с публикации.
- Публичная страница /tour/[id]: 360°-просмотр через Pannellum с кнопками
  переключения между комнатами.

## Ограничения и что доделать дальше

- Переходы между комнатами — кнопками внизу экрана, а не кликабельными
  точками (hotspots) прямо в панораме. Hotspots можно добавить позже,
  это отдельная фича (нужно будет задавать точку и направление на панораме).
- Нет приёма оплаты за использование сервиса (если нужна платная подписка
  клиентам — потребуется Stripe/ЮKassa).
- Нет сшивки нескольких обычных фото в панораму — сервис ожидает уже
  готовые equirectangular-панорамы.
- Email от Supabase по умолчанию уходит с их общего домена — для
  продакшена стоит подключить свой SMTP (Project Settings → Auth → SMTP).
